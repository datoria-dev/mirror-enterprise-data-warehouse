### 2. COPY (5 sec)

### 3. GO TO SNOWFLAKE (20 sec)
- https://app.snowflake.com/GenericCorp/west-europe.azure/

### 5. EDIT (30 sec)
- Click **"Edit"** button

- Click **"Save"**
- Click **"Run"**

### 7. VERIFY (30 sec)
✅ App loads
✅ No errors
✅ Tabs clickable
✅ Tables show data

## 🆘 Quick Troubleshooting

**App won't save?**
- Hard refresh: Ctrl+Shift+R
- Check browser console
- Try different browser

**Syntax error?**
- Re-copy file (may have missed lines)
- Check file path is correct

**No data in tables?**
- Check filters (may be too restrictive)
- Check date range
- Verify data exists in Snowflake
